API

free · 60 requests / minute / IP · no keys {{template "status" .}}

Everything on this site is served from one hourly-to-5-minute snapshot of Ethereum mainnet. The same numbers are available as JSON. No auth, no paid tier, CORS open. Please cache: responses only change when a sync runs (every 5 minutes), so polling faster than that returns the same bytes.

GET /api/v1/summary

Both platforms: today, 24h / 7d / 30d / all-time windows (volume, fees, protocol revenue, creator fees, trades, launches, graduations) and the platform token (price, 24h change, supply, burned, FDV, market cap).

curl -s https://{{.Host}}/api/v1/summary | jq '.platforms[] | {name, volume7d: .ranges["7d"].volumeUsd, fdv: .platformToken.fdvUsd}'

GET /api/v1/daily ?interval=day|hour

Time series. One row per UTC day (or hour) with a bucket per platform: volUsd, volEth, swaps, launches, graduations, creatorUsd, holderUsd, platformUsd, launchFeeUsd, creatorPaid, tokenPrice (platform token, last swap in the bucket), plus pricing-coverage counters unpriced and spotPriced.

curl -s "https://{{.Host}}/api/v1/daily?interval=day" | jq '.[-1]'

GET /api/v1/tokens ?pad=stockereum|sender &sort=volume|fdv|trades|new &q=text &page=N

Every launched token, 100 per page, same filters as the Tokens tab. Fields: address, platform, symbol, name, image, quote, quoteSymbol, poolId, creator, created, graduated, swaps, volumeQuote, volumeUsd, priceUsd, supply, fdvUsd.

curl -s "https://{{.Host}}/api/v1/tokens?pad=sender&sort=new&page=1" | jq '.tokens[:3]'

GET /api/v1/tokens/{address}

curl -s https://{{.Host}}/api/v1/tokens/0x75e2fc69ff2ac12af65ba7d321bbf4f878c535d2

GET /api/snapshot.json

The raw snapshot the server runs on: every token, pool id → token map, quote assets with prices and logos, hourly ETH/USD series, and the per-platform hourly aggregates keyed "<platform>/<hour unix>". A few MB; use it if you want to roll your own windows.

curl -s https://{{.Host}}/api/snapshot.json | jq '{head, tokens: (.tokens|length), hours: (.hours|length)}'

Limits & semantics

  • 60 requests per minute per IP, fixed window. Headers: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset; over the limit you get 429 with Retry-After.
  • Volume is the quote-side delta of every Uniswap v4 Swap on a launched pool. ETH/WETH quotes are priced hourly; other quotes at snapshot spot (spotPriced counts them); quotes with no feed add $0 (unpriced).
  • Fees are what the contracts credited or collected — Stockereum FeeEscrow.Credited, Sender locker FeesCollected / hook FeeDistributed — not volume × rate. creatorPaid is what actually left to creators.
  • Token prices come from the pool's sqrtPriceX96 after the last swap; FDV = price × totalSupply(). Thin pools print thin marks.
  • Data is 12 confirmations behind the tip and refreshed every 5 minutes. Not audited; no warranty. Attribution appreciated.
