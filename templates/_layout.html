Stockereum, Sender, Stroid and Clanker — Ethereum mainnet launchpad analytics (volume, launches, trades, fees, protocol revenue, platform-token price/FDV/burn), read directly from chain logs and refreshed every 5 minutes. Every platform launches tokens into Uniswap v4 pools. Volume is the quote-side delta of each Swap on a launched pool; ETH/WETH quotes are priced hourly, other quotes at snapshot spot. Fees are what the contracts credited or collected (Stockereum FeeEscrow.Credited, Sender locker FeesCollected / hook FeeDistributed, Stroid hook FeeAccrued / PartnerFeeAccrued, Clanker locker ClaimedRewards / hook ClaimProtocolFees), not volume x rate. Clanker fees count only when collected from the locked position. Token prices derive from the pool sqrtPriceX96 after the latest swap; FDV = price x totalSupply(). ## Pages - {{.Origin}}/ : Overview — leaderboard of every launchpad for 24h/7d/30d/all, then any two side by side (?a=&b=): charts, fee routing, buyback & burn, top coins - {{.Origin}}/tokens : every launched token, sortable, 100 per page - {{.Origin}}/api : API documentation ## JSON API (no auth, CORS open, 60 requests/min per IP) - {{.Origin}}/api/v1/summary : per-platform today / 24h / 7d / 30d / all windows, indexing progress and platform token stats - {{.Origin}}/api/v1/daily?interval=day|hour : time series per platform - {{.Origin}}/api/v1/tokens?pad=stockereum|sender|stroid|clanker&sort=volume|fdv|price|trades|new&q=&page= : token list - {{.Origin}}/api/v1/tokens/{address} : one token - {{.Origin}}/api/snapshot.json : raw snapshot Responses carry ETag / Last-Modified and only change when a sync runs. Data is 12 confirmations behind the tip; not audited.
